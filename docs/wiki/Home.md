# Knurl Wiki

Knurl is a local-first Android workout tracker. It stores workout plans, workout logs, rest-day notes, group workout data, and recovery data on the device.

## Current Version

- Current public version: `1.8`
- Android package: `com.homeops.gymtracker`
- Update channel: GitHub Releases

## Documentation Model

Gym Tracker uses two documentation layers:

1. In-app Help for short instructions users need while using the app.
2. GitHub Wiki pages for longer guides, troubleshooting, recovery steps, release notes, and maintainer notes.

The source copy for GitHub Wiki pages is kept in `docs/wiki/` so documentation changes can be reviewed and versioned with the app.
